# Система «ФармаКонтроль» (CDSS)
Прототип модуля поддержки принятия врачебных решений для контроля совместимости лекарственных препаратов и оценки эффективности фармакотерапии.

## Текущий этап (Этап 1):
- Спроектирована реляционная база данных в 3-й нормальной форме (4 связанные таблицы).
- Подготовлен SQL-скрипт (`schema.sql`) для развертывания базы в SQLite и наполнения первичными клиническими кейсами из справочника ГРЛС.

## Следующий этап:
- Разработка алгоритма проверки рецептов на Python и сборка веб-интерфейса врача (Streamlit).
